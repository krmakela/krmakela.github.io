## Course Introduction

The course **Command Line Tools for Linguists** teaches the essentials of working in a command-line environment, with special focus on tasks related to language technology. This includes learning to use basic tools for scripting, text processing and software management in a UNIX-like environment. The course utilizes blended teaching with emphasis on self-study that is supported by lecture videos and tutorials, along with one in-person support session per learning module.

The course consists of four modules and a final project. I will briefly describe their main contents and reflect on what I learned from them in the following summary.
